# Roblox Multi Launcher

Lance plusieurs Roblox en même temps, avec plusieurs comptes, sans rien installer.

## Installation
1. Télécharge `RobloxMulti.ps1` et `Lancer RobloxMulti.bat` (bouton **Code → Download ZIP**).
2. Mets-les dans le même dossier.
3. Double-clique sur **Lancer RobloxMulti.bat**.

Si Windows affiche « Windows a protégé votre ordinateur » : **Informations complémentaires → Exécuter quand même**.

## Mises à jour
Le launcher vérifie tout seul ce dépôt au démarrage et propose la mise à jour.

## Sécurité
- Aucun mot de passe n'est stocké.
- Les sessions sont chiffrées avec ton compte Windows, dans `%APPDATA%\RobloxMulti`, et ne quittent jamais ton PC.
- Ne partage jamais ce dossier.
